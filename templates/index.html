Phishing Detector

Check a suspicious link before you open it.

How was this created?

This project uses a Random Forest machine-learning model trained on a phishing-URL dataset and additional verified legitimate domains.

  • It checks URL signals such as length, digits, special characters, HTTPS, IP addresses, and brand-name similarity.
  • It also looks at basic page signals, such as page structure, links, mobile responsiveness, and iframes.
  • The model returns a prediction and confidence score, but it cannot guarantee a website is safe.
  • Some websites block automated checks. In that case, the app says it could not inspect the site instead of guessing.

This is an educational prediction tool, not a guarantee of safety. Do not enter passwords or personal information on a site you do not trust.
