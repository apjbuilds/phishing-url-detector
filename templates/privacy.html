Privacy Policy

This is a student project built to classify URLs as phishing or legitimate. Here's exactly what happens with your data:

What this site does with the URL you enter

When you submit a URL, the app checks it against a machine learning model and returns a prediction. The URL is processed in memory to generate that result and is not saved to any database. Nothing you submit is stored, tracked, or connected to you personally.

Standard hosting logs

This site is hosted on Render. Like virtually all web hosts, Render automatically keeps basic server logs (timestamps, browser type, response codes) for operational and debugging purposes. This is standard infrastructure logging, not something this project sets up or accesses for analysis.

No accounts, no tracking

This site doesn't use cookies, accounts, or analytics tools. There's nothing to sign up for and nothing being tracked across visits.
